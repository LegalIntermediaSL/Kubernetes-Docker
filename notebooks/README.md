# Notebooks

Esta carpeta contiene cuadernos Jupyter orientados a utilidades y aprendizaje aplicado.

## Cuadernos disponibles

- `01_generador_dockerfile.ipynb`
- `02_generador_manifiestos_k8s.ipynb`
- `03_planificador_recursos_k8s.ipynb`

## Para qué sirven

- Probar ideas rápidamente sin tocar aún los ejemplos finales.
- Entender cómo se construye un `Dockerfile` o un manifiesto YAML.
- Hacer estimaciones simples de capacidad y recursos.

## Cómo abrirlos

Opciones habituales:

- JupyterLab
- VS Code con soporte de notebooks

## Sugerencia de uso

1. Ejecuta cada notebook tal como viene.
2. Cambia parámetros pequeños.
3. Copia el resultado útil a `examples/` o a tus notas.
