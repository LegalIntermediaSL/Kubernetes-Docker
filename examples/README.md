## Cómo usar esta carpeta

- Entra primero por el `README.md` de la tecnología que quieras practicar.
- Ejecuta cada laboratorio tal como viene antes de modificarlo.
- Usa `docs/` para el contexto conceptual y `examples/` para la parte operativa.
