# Ejemplos Docker

Estos laboratorios cubren el recorrido práctico de Docker del repositorio.

## Orden recomendado

1. [hola-nginx](hola-nginx/README.md): imagen mínima basada en `nginx`.
2. [python-api](python-api/README.md): API Flask con variables de entorno y métricas.
3. [compose-web-api](compose-web-api/README.md): dos servicios conectados con `docker compose`.
4. [fullstack-demo](fullstack-demo/README.md): frontend, API y Redis.
5. [python-api-optimized](python-api-optimized/README.md): BuildKit, multi-stage y runtime no root.
6. [runtime-debug-demo](runtime-debug-demo/README.md): depuración de procesos, señales y runtime.
7. [volume-backup-demo](volume-backup-demo/README.md): persistencia, backup y restore de volúmenes.

## Qué practicar aquí

- Construcción de imágenes.
- Inspección de contenedores y logs.
- Variables de entorno.
- Redes entre servicios.
- Optimización de builds.
- Persistencia y limpieza operativa.
